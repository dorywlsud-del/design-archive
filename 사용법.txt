디자인 아카이브 — 사용법
================================================

1. 여는 방법
------------------------------------------------
· 폴더 안의 index.html 파일을 더블클릭하면 브라우저에서 바로 열립니다.
  (인터넷 연결이나 서버 설치가 필요 없습니다. Chrome, Edge, Safari, Firefox 모두 가능)

· 더블클릭으로 열리지 않으면 index.html 을 마우스 오른쪽 버튼으로 눌러
  [연결 프로그램] → [Chrome] (또는 사용 중인 브라우저)을 고르세요.

· 폴더째 다른 컴퓨터나 USB에 복사해도 그대로 열립니다.
  단, index.html · styles.css · app.js · data.js · images 폴더가
  항상 같은 위치에 함께 있어야 합니다.


2. 화면 조작
------------------------------------------------
· 마우스 드래그 ............ 화면을 붙잡고 상하좌우로 이동
· 휠 / 트랙패드 ........... 상하좌우 스크롤로 이동 (두 손가락 밀기 그대로)
· 방향키 ← ↑ ↓ → .......... 한 칸씩 이동 (Shift를 누르면 크게 이동)
· Home 키 ................. 처음 위치로 돌아오기
· 이미지 클릭 ............. 상세 설명 열기
· 핀터레스트 ............. 상세 설명의 [핀터레스트에서 관련 디자인 찾기 ↗] 를 누르면
                      그 자료의 영문 키워드로 검색한 핀터레스트 페이지가 새 탭에 열립니다.
· Esc 또는 바깥 클릭 ...... 상세 설명 닫기
· 휴대폰·태블릿 ........... 손가락으로 끌어서 이동, 이미지를 탭하면 상세 설명

오른쪽 위 [메뉴 열기] 버튼
· 용어·자료 검색 ... 제목, 영문명, 설명, 태그를 실시간으로 검색합니다.
                      예) 그리드 / 제본 / 리스그래프 / 2026 / 산세리프
· 카테고리 ......... 그래픽 레퍼런스 · 편집 디자인 · 북디자인 ·
                      타이포그래피 · 인쇄·제본 (각 항목 수 표시)
· 검색어와 카테고리는 함께 적용됩니다.

4. 자료를 직접 추가하는 방법
------------------------------------------------
① images 폴더에 사진 파일을 넣습니다. (예: images/my-poster.jpg)
② data.js 를 메모장으로 열고, 첫 번째 항목 { ... } 를 통째로 복사해
   배열 안의 맨 끝(마지막 } 뒤)에 붙여 넣은 뒤 내용을 고칩니다.

   {
     "id": "my-poster",                       ← 겹치지 않는 영문 이름
     "file": "my-poster.jpg",
     "img": "images/my-poster.jpg",           ← images 폴더 기준 경로
     "w": 1200, "h": 1600,                    ← 사진의 실제 가로·세로 픽셀
     "cat": "그래픽 레퍼런스",                  ← 아래 5개 중 하나
     "ko": "내가 좋아하는 포스터",
     "en": "My favourite poster",
     "pinKeywords": ["poster design", "grid"],  ← 선택: 핀터레스트 검색에 쓸 영문 키워드 2~3개
                                                  (없으면 영문 제목과 카테고리로 자동 생성)
     "maker": "디자이너 이름", "year": "2026", "kind": "오프셋 포스터",
     "points": ["첫 번째 디자인 포인트", "두 번째 디자인 포인트"],
     "tags": ["포스터", "그리드"],
     "credit": "출처 표기", "license": "라이선스",
     "link": "원본 주소"
   }

③ 저장하고 브라우저를 새로 고침(F5)하면 새 자료가 캔버스에 나타납니다.
   항목 수(N)는 data.js 를 읽어 자동으로 다시 계산됩니다.

※ cat 에 쓰는 값은 정확히 다음 다섯 가지 중 하나여야 필터에 잡힙니다.
   그래픽 레퍼런스 / 편집 디자인 / 북디자인 / 타이포그래피 / 인쇄·제본
※ 각 항목은 쉼표로 구분하고, 마지막 항목 뒤에는 쉼표를 붙이지 않습니다.


5. 참고
------------------------------------------------
· 이 페이지는 데이터를 data.js 파일에 직접 담아 두고 불러옵니다.
  (브라우저가 file:// 로 열린 페이지에서 data.json 같은 외부 파일 읽기를 막기 때문입니다.)
  그래서 서버 없이 더블클릭만으로 열려도 사진과 설명이 모두 보입니다.

· 사진을 바꾸려면 images 폴더의 파일을 같은 이름으로 덮어쓰면 됩니다.
  파일 이름을 바꿨다면 data.js 의 img 값도 함께 고쳐 주세요.

· 이미지는 원본의 긴 쪽을 1400px 정도로 줄여 두었습니다.
  더 선명한 화질이 필요하면 원본 기사에서 내려받아 같은 이름으로 바꿔 넣으세요.
