디자인 아카이브 — 사용법
================================================
뀨링 · 피클 · 클로드코드가 함께 관리하는 디자인 자료 아카이브입니다.
격주 월요일 오전에 업데이트합니다.
공개 주소: https://dorywlsud-del.github.io/design-archive/


1. 여는 방법
------------------------------------------------
· 위 공개 주소로 열거나, 폴더 안의 index.html 을 더블클릭하면 브라우저에서 바로 열립니다.
· 폴더째 복사해도 열립니다. index.html · styles.css · app.js · data.js · images 폴더가
  항상 같은 위치에 함께 있어야 합니다.


2. 화면 조작
------------------------------------------------
· 마우스 드래그 / 휠 / 트랙패드 / 방향키 ... 화면 이동 (Shift+방향키: 크게, Home: 처음 위치)
· 카드 클릭 ............ 상세 설명 (Esc 또는 바깥 클릭으로 닫기)
· 상세에서 ← → ......... 이전·다음 자료 (휴대폰은 좌우로 밀기)
· [링크 복사] .......... 그 자료가 바로 열리는 주소 복사 (주소 끝 #자료id)
· [핀터레스트에서 관련 디자인 찾기] ... 영문 키워드로 핀터레스트 검색을 새 탭에 엽니다.
· 오른쪽 위 [메뉴 열기] ... 검색 + 카테고리 필터 (함께 적용됨)


3. 분류 (2026-11-20 통일, 8개)
------------------------------------------------
  그래픽·브랜딩 / 편집디자인 / 북디자인 / 교육디자인 /
  타이포그래피 / 인포그래픽 / 어워드·행사 / 인쇄·제본

  ※ data.js 의 cat 값은 반드시 위 8개 중 하나와 글자까지 똑같아야 필터에 잡힙니다.
  ※ 협업 시트(Sheet 2)의 '카테고리' 칸에도 같은 이름을 씁니다.


4. 카드 보는 법
------------------------------------------------
· 신뢰도 ★★★ 공공기관·연구·전문기관 / ★★ 언론·업계 매체 / ★ 업체 블로그·홍보성
· 색이 칠해진 글자 카드 = 원문에 쓸 만한 대표 이미지가 없는 자료 (정책 기사·연구·공공 자료 등)
· 상세 화면 아래에 출처, 추가한 날짜, 추가한 사람(피클 / 클로드코드)이 적혀 있습니다.
· 상세 설명의 ※ 표시는 확인되지 않았거나 주의할 점입니다.


5. 업데이트 방식 (격주 월요일 오전)
------------------------------------------------
① 새 자료 후보는 협업 시트 「뀨링-클로드코드-협업-작업판」 Sheet 2 에 '대기' 상태로 올립니다.
   (번호 / 제목 / 카테고리 / 핀터레스트 키워드 / 출처 링크 / 반영 상태 / 비고)
② 업데이트 날 클로드코드가 '대기' 항목을 원문과 대조해 요점을 정리하고,
   대표 이미지를 받아 data.js 를 다시 만든 뒤 GitHub 에 배포합니다.
③ 반영한 항목은 Sheet 2 반영 상태를 '반영'으로 바꾸고, Sheet 1 에 회차 기록을 남깁니다.

자료 원본(items.json)과 빌드 도구는 로컬 작업 폴더 아카이브/결과물/_빌드도구 에 있습니다.


6. 저작권
------------------------------------------------
이미지는 각 원문 기사·페이지의 이미지이며 권리는 각 스튜디오·디자이너·매체에 있습니다.
개인 열람·연구용으로만 쓰고, 재배포·상업적 사용 전에는 원저작자에게 확인하세요.
